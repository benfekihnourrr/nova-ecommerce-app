 # 🛒 NOVA

## Modern E-commerce Shopping Web App

NOVA is a responsive e-commerce web application designed to provide customers with a modern and simple online shopping experience.

Customers can browse products, search and filter the catalog, view product details, save products to a wishlist, manage a shopping cart, place orders, and view their order history.

The application also includes an admin dashboard for monitoring orders, revenue, products, and inventory.

## ✨ Features

### 🛍️ Customer Experience

- Browse product catalog
- Search for products
- Filter products by category
- Sort products by price
- View detailed product information
- Add products to wishlist
- Add products to shopping cart
- Change product quantities
- Remove products from cart
- Place orders
- View order history
- Responsive mobile-friendly interface

### 🏷️ Product Categories

NOVA includes several product categories:

- Clothing
- Accessories
- Shoes
- Bags

### ❤️ Wishlist

Customers can save products they are interested in to their wishlist for easy access later.

Wishlist information is stored locally in the browser.

### 🛒 Shopping Cart

The shopping cart allows customers to:

- Add products
- Change quantities
- Remove products
- Review selected items
- Proceed to checkout

### 📦 Order Management

After placing an order, customers can access the **My Orders** section to view their order history.

### 🖥️ Admin Dashboard

The administration dashboard provides an overview of store activity, including:

- Total orders
- Revenue
- Product inventory
- Low-stock products
- Recent orders
- Store performance indicators

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage
- Responsive Web Design
- UI/UX Design

## 💾 Data Storage

NOVA uses browser Local Storage to save demo information such as:

- Shopping cart
- Wishlist
- Orders

This allows the application to demonstrate persistent shopping functionality without requiring a backend database.

## 🎯 Project Purpose

This project demonstrates the development of a complete front-end e-commerce experience.

It showcases product management, search and filtering, shopping cart functionality, wishlist management, order creation, local data persistence, responsive design, and administrative dashboard development.

## ⚠️ Demo Notice

NOVA is a front-end demonstration project. Shopping data and orders are stored locally in the user's browser.

The checkout experience is a demonstration and does not process real payments or use a production payment gateway.

For a production application, the project would require a secure backend, database, authentication system, and payment provider integration.
